# Оқу · Астана
Обновлённый редактируемый учебный сайт: холодный светлый фон, синие акценты, цветные карточки, большая строка поиска. Все курсы и цены демонстрационные.

## Структура
app.py — Flask, адреса страниц и 404.
data.py — чтение courses.json и поиск по ID.
filters.py — фильтрация и сортировка.
courses.json — данные курсов.
templates/ — страницы.
static/style.css — оформление.
static/main.js — избранное, сравнение и мобильные фильтры.
test.py — автотесты сервера.
НАЧНИ ЗДЕСЬ.txt — инструкция запуска всей папки.

## Обозначения в Python
Короткие буквенные переменные: a — приложение, d — все данные, c — курс/результат, q — параметры, e — ошибка, n — число, s — строка, x — текущий курс, p — путь, f — файл, v — направление.
Названия функций описывают действия. @a.route связывает адрес со страницей. __name__ и __file__ — специальные имена Python, их не меняют.
Рабочий бэкенд без классов, SQL и асинхронного кода. Класс есть только в автотестах стандартной библиотеки unittest.

## Что менять
courses.json: title — название; school — школа; subject — предмет; description — описание; price — целое число тенге за месяц; lessons — занятий за месяц; minutes — длительность занятия; level — уровень; address — адрес; schedule — расписание.
id — уникальное положительное целое число.
direction: Языки / ЕНТ / Программирование.
format: Онлайн / Офлайн.
type: Групповые / Индивидуальные.
Для проверенной настоящей школы: demo false и url — полная проверенная https:// ссылка. Тогда на странице курса появится переход к школе. Плашку демо в base.html убирай только после замены всех вымышленных данных настоящими. При реальных данных добавь в описание дату проверки цены. Не смешивай цену месяца и цену всего курса.
Не удаляй обязательные ключи JSON. Последний объект не заканчивается запятой.
Оформление — static/style.css; текст страниц — templates. После изменения Python перезапусти сервер.

## Логика
Фильтры работают одновременно. Бюджет — верхняя граница месячной цены.
Поиск в большой строке начинает новый поиск; переключатели направлений сохраняют текущие фильтры.
Избранное и сравнение — localStorage браузера, не синхронизация между устройствами. При блокировке хранилища показывается сообщение.
Максимум 3 курса в сравнении, повторное нажатие отменяет выбор. Адрес сравнения можно переслать. На телефоне фильтры свёрнуты и открываются нажатием.
Демо-курсы не имеют кнопки записи: такая функция не реализована. Нет аккаунтов, реальных отзывов, платежей, админ-панели или автоматического сбора Instagram.

## Тесты
После установки зависимостей Windows:
.venv\Scripts\python.exe test.py
macOS/Linux:
.venv/bin/python test.py
Ручная проверка: поиск, фильтры, направления, избранное после перезагрузки, сравнение 3 курсов и попытка добавить четвёртый, удаление из таблицы, пустые результаты, мобильный экран.
Автотесты не заменяют проверку кликов в браузере.

## GitHub + Python-хостинг
GitHub хранит код, но GitHub Pages не запускает Flask. В Python-хостинге, например Render, создай Web Service из своего репозитория.
В корне репозитория должны быть app.py и requirements.txt; папки templates и static сохраняются. Не загружай .venv и не загружай ZIP вместо распакованного содержимого.
Build Command: pip install -r requirements.txt
Start Command: gunicorn app:a
Тарифы и ограничения хостинга проверяй отдельно. Локально на Windows используй python app.py, не gunicorn.
